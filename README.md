# 美式音标

一个只练美式英语音标发音的离线学习 App。

## 设计原则

- 不播放单词，只播放音标对应的单音
- 用口型图解释嘴唇、舌头、下巴和声带
- 按中国学习者常见难点安排重点练习
- 用最小对比练习区分容易混淆的音
- 支持 PWA，可通过 GitHub Pages 安装到手机

## 学习顺序

1. 元音
2. 双元音
3. r 化元音
4. th、r/l、v/w、ng 等中国学习者重点音
5. 其他辅音
6. 混淆对比

## 手机使用

发布到 GitHub Pages 后，用手机打开页面并添加到主屏幕。第一次联网打开后，核心 App 会缓存到手机，之后可离线使用。
